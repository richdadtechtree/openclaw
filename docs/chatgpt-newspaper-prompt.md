# ChatGPT 신문 요약 지침 — 기사↔지면 연결용 (2026-09-24)

다이제스트 웹(`http://<서버>:8000/slack`)의 **📰 글+지면** 보기가 요약된 기사 옆에
그 기사가 실린 신문 사진(또는 **그 기사 부분만 잘라서**)을 붙이려면, 요약 끝에 아래 JSON 이 필요하다.
ChatGPT 의 **프로젝트 지침(또는 맞춤 지침)** 에 아래 블록을 그대로 붙여 넣는다.

---

```
[신문 요약 — 기사↔지면 연결 규칙]
사람이 읽는 요약(제목·WHAT·WHY·HOW)은 지금처럼 쓰고, 각 메시지 맨 끝에
그 메시지에 나온 기사들의 정보를 아래 JSON 으로 한 번 붙여라. 코드블록(```json)으로 감싼다.

```json
{"date":"YYYY-MM-DD","articles":[
  {"article_id":"YYYYMMDD-001","title":"요약에 쓴 기사 제목 그대로","page":3,"bbox":[0.05,0.12,0.90,0.35]}
]}
```

- title: 위 요약에 쓴 기사 제목을 **글자 그대로** 복사한다(웹이 제목으로 짝을 찾는다).
- page: 그 기사가 실린 **신문 PDF 쪽 번호**(1부터). = 사진 파일 번호(03.jpg → 3). 인쇄된 면 번호(A3 등)가 아니다.
- bbox: 그 쪽 안에서 기사(제목+본문)가 차지하는 네모 [왼쪽, 위, 너비, 높이]. 쪽 전체를 1로 본 **비율(0~1)**.
  확실하지 않으면 bbox 는 빼라(없으면 쪽 전체를 보여준다). 픽셀 값은 쓰지 않는다.
- 쪽 번호를 모르는 기사는 articles 에 넣지 마라(지어내지 않는다).
- 한 기사가 두 쪽에 걸치면 제목이 있는 쪽 하나만.
```

---

## 참고
- JSON 은 웹 화면에 **보이지 않는다**(자동으로 숨김). 슬랙에는 그대로 보인다.
- 요약이 여러 메시지(1/6 … 6/6)로 나뉘어도 각 메시지 끝에 붙이면 된다.
- JSON 이 없거나 빠진 기사는 → `• 사진: 07` 줄 → 서버의 지면 글자 대조(자동) → 📌 직접 연결 순으로 대신한다.
- 우선순위: 📌 직접 연결 > 요약 JSON > `• 사진: NN` > 지면 글자 대조(자동).
- 개인용 서버라 지면 사진을 쓰지만, **외부 공개 사이트로 바꾸면 신문 지면·기사 사진 게시는 저작권 문제**가 될 수 있다.
