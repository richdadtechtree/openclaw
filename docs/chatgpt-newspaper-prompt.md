# ChatGPT 신문 요약 지침 — 적용 방법 (2026-10-01 개정)

전체 지침 본문은 **`docs/chatgpt-newspaper-instructions.md`** 에 있다.
지침이 길어 ChatGPT 의 지침 칸에서 보기·고치기 어렵기 때문에, 아래처럼 **둘로 나눠** 넣는다.

## 1. 프로젝트 파일로 올리기 (전체 지침)
ChatGPT → 신문 요약에 쓰는 **프로젝트** → **파일 추가** → `chatgpt-newspaper-instructions.md` 를 올린다.
(예전 지침 파일이 있으면 지운다. 지침이 두 개면 섞인다.)

## 2. 지침 칸에는 아래 짧은 글만 (통째로 바꿔 넣기)

```
신문 요약을 할 때는 이 프로젝트의 파일 「chatgpt-newspaper-instructions.md」의 지침을 처음부터 끝까지 그대로 따른다.

특히 아래 4가지는 절대 빠뜨리지 않는다. Slack 에 보내기 직전에 다시 확인한다.
1. 기사마다 「• 사진: NN」 줄 (NN = 그 기사가 실린 PDF 쪽 번호, 2자리)
2. Slack 메시지 하나하나의 맨 끝에 「기사↔지면 JSON」(```json 코드블록, evidence 포함). 메시지를 1/6…6/6 으로 나누면 6개 모두에 각각.
3. 숫자·단위·기준시점을 지면과 대조. 지면에 없는 내용은 쓰지 않는다.
4. 사용자에게 보여주는 최종본과 똑같은 전문을 Slack #gpt 에 전송.

JSON 과 「• 사진:」 줄은 웹 화면에서 자동으로 숨겨지므로 읽기 불편을 걱정해 빼지 않는다.
```

## 3. 예약 실행(매일 아침 작업)도 확인
ChatGPT 에 **예약 작업(매일 오전 7시 "아침 신문 검수·발송")** 이 있으면, 그 작업의 지시문에도 한 줄 추가한다:

```
요약 형식과 Slack 전송은 프로젝트 파일 「chatgpt-newspaper-instructions.md」를 따르고, 기사마다 「• 사진: NN」 줄과 메시지마다 끝에 기사↔지면 JSON 을 반드시 붙인다.
```

> 2026-10-01 실제 사례: 예약 작업으로 보낸 요약 6개 메시지에 **JSON 과 `• 사진:` 줄이 하나도 없었다** →
> 웹이 지면 글자 대조(자동)에만 의존해 짧은 기사·표 위주 기사(예: "내 집 마련 전략·유망 정비사업지 알려준다")가 지면과 연결되지 않았다.
> 긴 지침의 맨 끝에 있던 JSON 규칙을 GPT 가 빠뜨린 것 → 지침 맨 앞(0장)과 지침 칸·예약 작업에 반복해 넣었다.

## 웹이 이 형식을 읽는 방식 (참고)
- 지면 연결 우선순위: 📌 직접 연결 > 요약 JSON(`page`·`bbox`) > `• 사진: NN` > 지면 글자 대조(자동).
- JSON·`• 사진:` 줄은 화면에서 숨긴다. 슬랙에는 그대로 보인다.
- 제목 앞 🔵(검수 통과)·⏸(검수 보류, 슬랙 표기 `:double_vertical_bar:`)는 작은 배지로 보인다.
- `evidence`(근거 원문·숫자)는 **지면 형광펜 자동 표시**(개발 예정)에 쓴다. 지금 넣어 두어도 화면은 깨지지 않는다.
- 개인용 서버라 지면 사진을 쓰지만, **외부 공개 사이트로 바꾸면 신문 지면·기사 사진 게시는 저작권 문제**가 될 수 있다.
