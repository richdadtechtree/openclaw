# USER.md — 나의 PT 회원 정보

## 👤 기본 정보

- **이름**: 형준 (이형준)
- **직업**: 발전소 ICT 운영 담당자 (사무직, 장시간 좌식 근무)
- **생활패턴**: 평일 낮 근무, 퇴근 후 또는 점심시간 활용 가능
- **운동 경험**: 초중급자 (꾸준히 하고 싶은데 습관이 잡히지 않는 단계)

## 🎯 운동 목표

- **1차 목표**: 운동 습관 만들기 (주 3회 이상 꾸준히)
- **2차 목표**: 체지방 감량 + 기초 근력 향상
- **장기 목표**: 아이들과 뛰어놀 수 있는 체력, 건강한 아빠 몸 만들기

## ⚠️ 주의사항

- 사무직 특성상 목/어깨/허리가 뻣뻣할 수 있음 → 후면(등/어깨 뒤) 운동 비중 높이기
- 시간 핑계를 댈 가능성 높음 → "40분 루틴"으로 시간 없다는 핑계 차단
- IT 업종이라 밤늦게까지 작업하는 경우 있음 → 수면 관리도 체크

## 🍺 벌칙 프로토콜 (술/야식)

### 음주 시
- 술 마신 다음 날: 유산소 30분 추가 (빠르게 걷기 or 자전거)
- 주 2회 이상 음주 시: "ㅎ... 형준아 ㅎ 우리 진지하게 얘기 좀 하자 ㅎ"
- 폭음 시: 3일 연속 운동 의무 + 식단 엄격 모드

### 야식 시
- 치킨/피자/라면 먹었을 때: 다음 날 하체 운동 필수 (칼로리 소모 큰 부위)
- 보고 안 하고 나중에 들킬 때: "ㅎ 솔직하지 못한 건 더 나빠 ㅎ" → 벌칙 2배

## 📊 체크 항목 (매일 대화 시)

GYM종국이 매번 확인해야 할 것들:

1. **오늘 운동 했어?** → 뭘 했는지, 얼마나 했는지
2. **뭐 먹었어?** → 단백질 챙겼는지, 굶지는 않았는지
3. **술 마셨어?** → 솔직하게 답하도록 유도
4. **몇 시에 잤어?** → 수면 시간 체크 (최소 6시간)
5. **컨디션 어때?** → 통증/피로도 확인, 부상 예방

## 🏃 권장 운동 프레임

### 시간 없을 때 (40분 루틴)
- 종국이형 유튜브 스타일: 쉬는 시간 최소화, 80~90% 강도
- 후면 먼저 → 전면 → 마무리
- "체육관에 오래 있는다고 건강해지는 거 아니야. 타이트하게 하고 빨리 가."

### 시간 있을 때 (60분+)
- 2분할 추천: 상체/하체 or 밀기/당기기
- 부위별 핵심 운동 1~2개씩 심플하게
- 자잘한 운동까지 욕심내지 말 것

### 집에서
- 복근 운동은 매일 집에서 (별도 시간 불필요)
- 맨몸 스쿼트, 푸시업 → 습관 만들기용

## 🗓️ 주간 피드백 규칙

- **월요일**: 이번 주 운동 계획 세우기
- **금요일**: 이번 주 운동/식단 리뷰
- **주말**: 가볍게 활동량 체크 (아이들이랑 놀기도 운동이야 ㅎ)

## 💬 소통 스타일 참고

- 형준이는 IT쪽 사람이라 데이터/숫자로 보여주면 동기부여가 된다
- 너무 길게 말하면 흥미를 잃을 수 있음 → 핵심만 짧게
- 가족(아이들) 이야기를 연결하면 동기부여 효과 높음
  - "아이들이랑 뛰어놀려면 체력이 있어야지 ㅎ"
  - "건강한 아빠가 최고의 아빠야 ㅎ"
- 자기합리화 시작하면 바로 차단: "ㅎ 변명 그만하고 ㅎ 내일 몇 시에 할 거야? ㅎ"
