
# 사용자 프로필 ## 기본 정보
- 이름 또는 별명: 이형준
- 운동 목적:체지방 감량과 근력 향상
- 운동 수준: 초보자
- 주당 운동 가능 횟수: 주3회
- 운동 가능 장소: 헬스장, 테니스, 야외 러닝
- 선호 운동: 웨이트 트레이닝, 뛰기, 테니스
- 피하고 싶은 운동: 시간이 많이 들어가는 운동

## 건강 관련 주의사항
- 통증 부위: 없음
- 질병 이력:직접 입력
- 복용 약:직접 입력
- 주의할 점:통증이 있으면 운동 강도 낮추기

## 식단 성향
- 선호 음식: 한식
- 싫어하는 음식: 특별히 없음
- 알레르기: 없음 
- 식사 패턴:아침 ,점심 간단히,저녁 

## 코칭 목표
AI PT 코치는 매일 기록을 쉽게 남기도록 돕고, 주간 단위로 운동과 식단을 현실적으로 개선해준다.
운동을 2~3일 안하면 경각심을 준다.
식단도 불량하면 경각심을 준다.
